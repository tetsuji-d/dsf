DSF / DSP 表紙プレビュー — Windows x64 検証版

このZIPは解凍して使います。まだ一般配布用の署名付きインストーラーではありません。
Windows 11 x64の開発端末で検証しています。ARM64・Mac・iOS・Android用ではありません。

できること
- Explorerのファイル一覧に、DSFの画像表紙と、新しく保存したDSPの表紙PNGを表示します。
- 表紙の右下に、青いDSF／緑のDSPの種類表示を重ねます。原稿内の表紙画像は加工しません。
- 表紙PNGがない古いDSP、Flowから始まるDSP、固定テキストのDSF表紙などは通常アイコンのままです。
- ページをめくる本文プレビューは第2段階のため、まだ含まれません。
- 本文・画像素材・原稿ファイルは書き換えず、通信しません。

現在の制約
- 開発ツール内のユーザー登録はWindowsの隔離領域に入り、実際のExplorerには反映されていませんでした。
  再起動では直らないことを確認済みです。下記の「種類ラベルを反映」を実ユーザー側で行う必要があります。
- 2026-10-03、本人による登録後、Explorerで青いDSF／緑のDSPのラベル表示を確認しました。
  表紙のない旧DSPは通常アイコンを維持しました。新規PCでの導入はまだ未検証です。
- 通常のローカルフォルダーで表紙表示を確認しています。
- この開発PCでは、OneDrive内のファイルは表紙の取得待ちになり、種類別アイコンのままです。
  同じファイルのローカルコピーでは表紙を表示できました。OneDrive内の表紙表示は未解決です。
- 古いDSPに表紙用画像がない場合は、新しいStudioで保存した版が必要です。
  Flow表紙など未対応の構成は、保存し直しても通常アイコンのままです。

導入時の変更
- 管理者確認が必要です。Program Filesに小さなWindows部品を置きます。
- PC単位で.dsp/.dsfの表紙表示と、サムネイル用の種類表示を登録します。
- 既定の「開く」アプリ、種類別アイコン、PWA、クラウド設定は変更しません。
- 他の表紙表示部品がすでに登録されている場合は上書きせず停止します。
- このユーザーのDSF Studio専用登録にも、サムネイル用の種類表示を設定します。
  元の値を記録し、解除時に戻します。ブラウザー共通の登録や「開く」コマンドは変更しません。
- WebPの読み取り機能を同梱しています。画像拡張の追加インストールは不要です。

管理者PowerShellで、解凍したフォルダーへ移動して実行します。
内容確認のみ: .\setup.ps1 -Action Status
導入:         .\setup.ps1 -Action Install
更新:         新しい検証版を解凍し、そのsetup.ps1で同じInstallを実行
解除:         .\setup.ps1 -Action Uninstall

管理者確認に別のWindowsアカウントを使った場合は、ふだんのユーザーのPowerShellで
.\user-badges.ps1 -Action Install を実行して、そのユーザーの種類表示を反映します。
PWAの再インストールで登録が変わった場合も、同じ操作で再確認できます。
解除前には、種類表示を設定した各ユーザーで .\user-badges.ps1 -Action Uninstall を実行してください。

種類ラベルを反映（Windows部品が導入済みの場合）
1. ふだん使うWindowsのエクスプローラーで、この解凍済みフォルダーを開きます。
2. APPLY-LABELS.cmd をダブルクリックします。管理者として実行する必要はありません。
3. 表示された結果を確認し、原稿フォルダーに戻ってF5を押します。
この操作は、そのユーザーのDSF Studio専用の種類ラベルだけを登録します。
本文・表紙・既定アプリ・普通のファイルアイコンは変更しません。
結果は同じフォルダーの label-registration.log に追記されます。
開発ツールのターミナル内から起動した結果だけで、Explorerへ反映したとは判断しないでください。

スクリプトの実行やソフトウェアの導入がWindowsの管理ポリシーで禁止されている場合は、
ポリシーを変更せず停止してください。

解除後、Windowsがまだ部品を使用している間はファイルだけが残ることがあります。
その場合は表示された案内に従い、解放後にUninstallを再実行します。
原稿や他アプリの関連付けを削除する操作ではありません。
