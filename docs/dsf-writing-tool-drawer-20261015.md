# Writingのスマホ用ツールドロワー（2026-10-15）

## 操作

- 幅900px未満では、Writing開始時はツールを収納し、ページ上端付近に小さな取っ手だけを表示する。
- 取っ手を下へ引くとツール列が開き、上へ戻すと収納する。取っ手のタップ／Enterでも開閉できる。
- 道具列の左右スクロールは継続する。列上での縦スワイプでも収納できる。横操作と縦操作は方向が確定してから処理する。
- スマホでは時間経過による自動収納を行わない。PCの自動収納は維持する。
- 「非表示」ボタンを削除。選択道具名・色・太さの独立したバーも全画面幅で非表示にする。設定は選択中の道具の再タップまたは長押しから開ける。
- 9px未満はドラッグとして扱わず、縦移動28pxを境に開閉する。短い移動やOSのキャンセルは元に戻す。二本指操作とペン入力はドロワーの対象外。

## 検証

- ブラウザー390×844で、収納した取っ手からの下ドラッグ、開いた取っ手からの上ドラッグ、再表示と横スクロールを確認。
- ツールの長押しタイマーは縦ドラッグ開始時に解除し、スワイプ後のクリックによる道具変更を抑止する。
- `verify-tool-drawer.mjs`で上下移動、短距離、横スクロール非干渉、クリック抑止、キャンセル、二本指、PC／ペン除外を確認。
- レイアウト、Reader接続とページめくり、viewportガード、Writing配信梱包の検証とステージング用ビルドを実施。
- ユーザーの指示によりステージング公開の対象とする。公開結果は `outputs/writing-w1/tool-drawer-20261015/staging-release.json` に記録する。実機iPhoneの指操作は公開後にユーザーが確認する。
