# Flow本文罫線ガイド

2026-09-01。Flow直接編集の安全な表示補助として、本文の行／列送りを示す罫線を追加する。

## 動作

- 右パネルの「表示補助」で`なし`／`罫線`を切り替える。
- 横書きは本文行送りに合わせた横罫、縦書きは本文右端を起点に列送りへ合わせた縦罫を表示する。
- 複数ページ表示と横スクロールで後からmountされたページにも同じ設定を適用する。
- 直接編集を終了すると罫線を隠す。選択したモードは現在のStudioセッション中だけ保持する。

## 安全境界

- `.flow-editor-page-surface`内の既存`.flow-dom-content`背景だけを変更する。
- canonical本文サイズと、paginationが解決した`fontSize × lineHeight`を使用する。
- Flow本文、ページ数、保存schema、History、autosave、Press、Viewer、書き出しには接続しない。
- ガイド切替によるreflowやページ再生成は行わない。

## 今回含めないもの

方眼は本文の基準文字送りを示せるが、倍率の異なる見出しや比例幅の欧文とは一致しないため別単位とする。
インデント、均等揃え、罫線の色／ピッチ設定、印刷／Viewerへのガイド表示も含めない。
