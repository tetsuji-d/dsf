# 行ガイド・本文領域フェンス・まとまり配置

## 行ガイドと本文領域フェンス

- Editorの「行ガイド」は、実際に描画された本文の行・列の座標からSVGを作る。ルビ・圏点は本文行の集計から除外する。等間隔の背景罫線は使わない。
- 本文編集時の表示補助であり、文書、改ページ計算、保存・発行データを変更しない。
- Flowの画像／図形選択時、FlowLayout.paddingで定義した本文領域をフェンスとして表示する。外側は淡色表示。
- 移動時は外周が本文領域境界から5論理px以内に来た場合に吸着する。回転後の外周・図形の線幅・キャプションを判定に含める。移動／拡縮／回転の確定位置が領域外なら元に戻す。従来の組版検証も確定時に実行する。
- Viewer右上の「読書ガイド」からON/OFF・表示対象・濃さを設定する。初期OFF、表示対象は「読んでいる行だけ」。本文タップで縦書きRTLは本文の左、横書きは下に細い目印を出す。本文・ルビ・圏点の文字範囲を計測し、ルビ・圏点と交差する区間は線を描かない。本文背景・文字色は変更しない。「すべての行」を選ぶと他の行には細いガイドを表示する。読者のブラウザ内だけに設定を保存し、作品や印刷には反映しない。ON時のページ移動はスワイプまたは矢印を使用。WebP画像ページに本文行の座標はないため対象外。
- Viewer設定はブラウザのlocalStorageだけに保存する。作者のデータ・DSF・印刷結果には反映しない。UI JA/EN対応。

## 保存仕様：FlowLayout v4（2026-09-12 承認・実装済み）

通常ページのまとまり配置を扉作成から切り離す。「このページ」の配置ボタンは段落・翻訳を分割せず、改ページと原稿内容を保持する。行内の文字揃えは既存の段落単位操作、行のまとまり配置は今回のページ単位操作として扱う。

```json
{
  "schemaVersion": 4,
  "pagePlacements": [
    {
      "id": "placement-id",
      "blockId": "paragraph-id",
      "languageKey": "ja",
      "utf16Offset": 120,
      "blockAlign": "center"
    }
  ]
}
```

- `flow.layout.pagePlacements` は任意。配置を明示適用したGroupだけv4へ移行する。既存v1/v2/v3は読み込み時に自動変換しない。画像・キャプションの編集でもv4を降格しない。未知のバージョンは拒否する。
- 各エントリは上記5フィールドのみ。IDは一意、言語キーは保存された表記を保持する。対象本文が存在し、UTF-16位置が0以上・本文長以下の書記素境界であることを検証する。扉領域内への配置アンカーは認めない。
- ページ番号や生成後の座標は保存しない。アンカーを含む生成ページに適用する。範囲は開始を含み終了を含まない。段落末尾位置だけはその段落の最終fragmentに含める。
- `start / center / end` を保存する。縦書きでは右／中央／左、横書きでは上／中央／下。原文と翻訳はそれぞれ独立した設定とする。
- 本文編集の変更範囲より後ろのアンカーは文字数差分で移動する。置換範囲内のアンカーは置換後の末尾へ移す。位置ちょうどへの挿入は後方に追随する。書記素を分断する位置は直後の境界へ補正する。
- 明示的な段落分割・結合、Flowの分割・接続でもIDと位置を追随させる。段落削除時はその段落のアンカーも削除する。翻訳本文の編集・翻訳結果の反映は該当言語だけを更新する。
- 再ページ化で異なる配置のアンカーが同一ページへ集まった場合、どちらも保存したまま競合を表示し、そのページへの追加移動は適用しない。同じ配置値なら併用できる。配置ボタンを明示選択すると、そのページ・言語の設定を1つに統一する。他のページ・言語の設定は保持する。

## 組版・画像・保存・発行

改ページ計算後に実測した本文（ルビ・圏点を含む）と画像・図形・キャプションの外周を一組として平行移動する。本文との相対位置、回り込み範囲、原稿fragmentを変更しない。対象軸の外周が本文領域に収まらない場合は移動せず、理由を表示する。

Editor、サムネイル、発行プレビューは同じ配置計算を使用する。画像操作ハンドルは画像と一緒に移動し、本文領域フェンスはページ上に固定する。UndoとDSP保存復元で配置アンカーを保持する。生成後の `placementOffset` は実行時だけの派生値で、Flowの保存データには混入させない。

発行時も認定フォントで配置を再計算し、競合・未解決・参照不明の設定があれば理由を表示して停止する。配信は既存fixedText座標と背景画像へ確定する。Project v6、DSP meta v2、DSF配信スキーマ、Firestore Rulesは変更しない。Viewerで再組版しない。

既存の扉設定は保持する。明示的な扉への変更では、対象段落の配置アンカーを全言語で除去し、既存の共有 `titleRegion` に切り替える。扉作成に限り、翻訳付き段落途中の分割・回り込み画像との併用制限は残る。同一段落の連続fragmentはまとめて範囲検証し、欠落や本文不一致は拒否する。

## 読書補助（試作確認後、実Viewerへ接続）

- `scripts/fixtures/viewer-reading-assist-ui.html`で「行ガイド／集中表示／拡大鏡」を比較する。
- 集中表示は対象行とルビ・圏点を鮮明に維持し、他の行だけを弱くぼかす。
- 拡大鏡は初期2倍、1.5／2／3倍切替。本文のマウス位置／タッチドラッグに追従し、脇の固定枠へ対象行と注釈を拡大する。長い行は位置に応じて部分表示する。
- 前後の行ボタンと方向キーも用意する。ボタン配置は縦書きRTLで左＝次の行・右＝前の行、横書きで上＝前の行・下＝次の行とする。試作は日本語縦書きRTLと英語横書きLTRの固定サンプル。
- 実Viewerの読書ガイドに「集中表示」「拡大鏡」を追加。縦書きでは左右キー、横書きでは上下キーで対象行を移動する。
- 拡大枠は縦書きでは右側、横書きでは下側の横長枠。空間を確保するときはページ全体を等比縮小し、改行・文字位置・配信座標は変更しない。枠内では選択行だけを複製し、ルビ・圏点も元座標のまま拡大する。
- 配信の注釈には本文行IDがないため、同じ基本スタイルと座標の重なり・距離から本文行へ関連付ける。関連が判定できない注釈はぼかさず残す。実行時DOMだけの関連付けで、配信スキーマは変更しない。
- 集中表示／拡大鏡では本文のマウス移動・1本指のドラッグを読書補助に使う。ページ送りは画面の矢印、ピンチは既存のページ拡大を維持する。拡大後のドラッグは既存のページパンを優先する。通常の行ガイドでは従来のスワイプを維持する。
- ページを移動すると行選択を解除する。画像だけのページは行座標がないため対象外。設定はlocalStorageだけで、DSF保存仕様・印刷・作品データは変更しない。
- `scripts/verify-viewer-reading-assist-browser.cjs`：実Flow→Viewerプレビューで縦横、注釈保持、集中表示、倍率、方向別ボタン、タッチ、モバイル、終了と作者データ不変を検証。
