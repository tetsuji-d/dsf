# 行ガイド・本文領域フェンス・まとまり配置

## 行ガイドと本文領域フェンス

- Editorの「行ガイド」は、実際に描画された本文の行・列の座標からSVGを作る。ルビ・圏点は本文行の集計から除外する。等間隔の背景罫線は使わない。
- 本文編集時の表示補助であり、文書、改ページ計算、保存・発行データを変更しない。
- Flowの画像／図形選択時、FlowLayout.paddingで定義した本文領域をフェンスとして表示する。外側は淡色表示。
- 移動時は外周が本文領域境界から5論理px以内に来た場合に吸着する。回転後の外周・図形の線幅・キャプションを判定に含める。移動／拡縮／回転の確定位置が領域外なら元に戻す。従来の組版検証も確定時に実行する。
- Viewer右上の「読書ガイド」からON/OFF・表示対象・濃さを設定する。初期OFF、表示対象は「読んでいる行だけ」。本文タップで縦書きRTLは本文の左、横書きは下に細い目印を出す。本文・ルビ・圏点の文字範囲を計測し、ルビ・圏点と交差する区間は線を描かない。本文背景・文字色は変更しない。「すべての行」を選ぶと他の行には細いガイドを表示する。読者のブラウザ内だけに設定を保存し、作品や印刷には反映しない。ON時のページ移動はスワイプまたは矢印を使用。WebP画像ページに本文行の座標はないため対象外。
- Viewer設定はブラウザのlocalStorageだけに保存する。作者のデータ・DSF・印刷結果には反映しない。UI JA/EN対応。

## 保存仕様：FlowLayout v4（2026-09-12 承認・実装済み）

通常ページのまとまり配置を扉作成から切り離す。「このページ」の配置ボタンは段落・翻訳を分割せず、改ページと原稿内容を保持する。行内の文字揃えは既存の段落単位操作、行のまとまり配置は今回のページ単位操作として扱う。

```json
{
  "schemaVersion": 4,
  "pagePlacements": [
    {
      "id": "placement-id",
      "blockId": "paragraph-id",
      "languageKey": "ja",
      "utf16Offset": 120,
      "blockAlign": "center"
    }
  ]
}
```

- `flow.layout.pagePlacements` は任意。配置を明示適用したGroupだけv4へ移行する。既存v1/v2/v3は読み込み時に自動変換しない。画像・キャプションの編集でもv4を降格しない。未知のバージョンは拒否する。
- 各エントリは上記5フィールドのみ。IDは一意、言語キーは保存された表記を保持する。対象本文が存在し、UTF-16位置が0以上・本文長以下の書記素境界であることを検証する。扉領域内への配置アンカーは認めない。
- ページ番号や生成後の座標は保存しない。アンカーを含む生成ページに適用する。範囲は開始を含み終了を含まない。段落末尾位置だけはその段落の最終fragmentに含める。
- `start / center / end` を保存する。縦書きでは右／中央／左、横書きでは上／中央／下。原文と翻訳はそれぞれ独立した設定とする。
- 本文編集の変更範囲より後ろのアンカーは文字数差分で移動する。置換範囲内のアンカーは置換後の末尾へ移す。位置ちょうどへの挿入は後方に追随する。書記素を分断する位置は直後の境界へ補正する。
- 明示的な段落分割・結合、Flowの分割・接続でもIDと位置を追随させる。段落削除時はその段落のアンカーも削除する。翻訳本文の編集・翻訳結果の反映は該当言語だけを更新する。
- 再ページ化で異なる配置のアンカーが同一ページへ集まった場合、どちらも保存したまま競合を表示し、そのページへの追加移動は適用しない。同じ配置値なら併用できる。配置ボタンを明示選択すると、そのページ・言語の設定を1つに統一する。他のページ・言語の設定は保持する。

## 組版・画像・保存・発行

改ページ計算後に実測した本文（ルビ・圏点を含む）と画像・図形・キャプションの外周を一組として平行移動する。本文との相対位置、回り込み範囲、原稿fragmentを変更しない。対象軸の外周が本文領域に収まらない場合は移動せず、理由を表示する。

Editor、サムネイル、発行プレビューは同じ配置計算を使用する。画像操作ハンドルは画像と一緒に移動し、本文領域フェンスはページ上に固定する。UndoとDSP保存復元で配置アンカーを保持する。生成後の `placementOffset` は実行時だけの派生値で、Flowの保存データには混入させない。

発行時も認定フォントで配置を再計算し、競合・未解決・参照不明の設定があれば理由を表示して停止する。配信は既存fixedText座標と背景画像へ確定する。Project v6、DSP meta v2、DSF配信スキーマ、Firestore Rulesは変更しない。Viewerで再組版しない。

既存の扉設定は保持する。明示的な扉への変更では、対象段落の配置アンカーを全言語で除去し、既存の共有 `titleRegion` に切り替える。扉作成に限り、翻訳付き段落途中の分割・回り込み画像との併用制限は残る。同一段落の連続fragmentはまとめて範囲検証し、欠落や本文不一致は拒否する。

## 読書補助（実Viewer）

- `scripts/fixtures/viewer-bottom-navigation-ui.html?preview=reading-window`の確認済み試作を実Viewerへ反映。
- 集中表示は対象行とルビ・圏点を鮮明に維持し、他の行だけを弱くぼかす。通常表示と同じページ寸法を使う。
- 拡大鏡は初期2倍、1.5／2／3倍。元の固定テキスト・注釈の座標を保持し、対象行の表示窓を拡大する。本文を再組版しない。原ページを画面内で最大表示したまま、コンパクトな拡大枠を重ねる。本文のタップ・なぞり操作で対象行・位置を選ぶ。縦書きは選択行と反対側、横書きは上下の空けやすい側へ配置する。
- 「続きを読む／戻る」は表示窓単位で移動。縦書きは直前2文字、横書きは可能なら直前1単語を残し、行末から次の行頭へ進む。前の行へ戻ると末尾の表示窓に戻る。単語が窓に収まらない場合は文字単位で送る。次ページへの移動は外側のページボタンで行う。
- 表示窓は元のDOMのgrapheme実測位置から決定。ルビ・圏点を独立した本文として数えず、本文の所属行と一緒に表示する。指／マウスのドラッグとホイールでも連続して送れる。
- スマホは常時、拡大鏡ではPCも、ページ矢印・進捗バー・行／文字送りを下部へ集約。既存コントロールを移動して元のページ操作を維持。通常のPC表示に戻したら元の場所へ復帰する。
- 内側は縦書きRTLで左＝次／右＝前、横書きで上＝前／下＝次。外側のページ方向は既存の作品言語設定に従う。PCでは下部メニューをページ上へ重ねる。スマホでは非表示時にページを最大表示し、表示時は上下同じ高さのメニュー余白を確保して縮小する。どちらも画面中央を維持する。帯全体は透明にし、ボタンと番号の背景だけでコントラストを確保する。
- `viewport-fit=cover`とsafe-areaを使用。下部の無操作帯は`max(28px, safe-area-inset-bottom + 16px)`、ボタンは44px以上。ヘッダーと左右端もsafe-areaに従う。下部操作や無操作帯へのタップではメニュー表示を切り替えない。
- 読書中の自動メニュー表示／非表示を抑制。本文・訳文・注釈・配信座標・保存schema・印刷内容は不変。読者設定のみ既存localStorageに保存する。
- 新しいテキストページは先頭行から再開。画像ページでは拡大鏡の対象がない旨を表示し、ページ送りを継続できる。終了後は元のページ表示と既存ピンチ／パン操作へ戻る。
- 検証: `scripts/verify-viewer-reading-window.js`（窓送り・境界・重複）と`scripts/verify-viewer-reading-assist-browser.cjs`（実Flow→Viewer、日英、注釈、文字／行送り、タッチ、safe-area、ページ移動、ピンチ／パン、印刷、作者データ不変）。iPhone実機でのホームバー操作は別途確認する。

### スマホのページ数とメニュー入口

- 初期状態はメニュー非表示。ページ数だけを下端に表示し、44px以上のタップ領域とホームバーの安全余白を確保する。
- ページ外の余白またはページ数でメニューを開く。通常読書中は本文タップでメニューを開かず、表示中の本文タップで閉じる。
- 読書補助中は本文を行選択に使用し、ページ数で開閉する。行送り・ページ送りではメニュー状態を維持する。
- メニューの実際の高さ（paddingを含む）を監視して中央配置を再計算する。倍率変更だけで、組版や保存内容を変えない。

### Viewerの曲面ページめくり

- `viewer-page-curl.js`は一時的な表示レイヤーを生成する。固定組版の本文・画像・ルビ・圏点・バブルをそのまま複製し、作者データとファイル形式は変更しない。
- 単ページでは同じ見開き内を横移動し、見開き境界で紙の裏面を表示する。見開きでは左右の対応を保って紙をめくる。bookモデルがない場合も既存の表紙単独・後続2ページ組の規則を使う。
- 24分割の曲面は表裏の切り取りを両側へ1.25px延長する。静止時は複製を破棄し、通常のページ描画に戻す。
- ページボタンと、ズームしていない状態でページ端から始めるタッチの横ドラッグに対応。進行4割未満は戻す。ページ位置・しおりの変更は確定後のみ。
- 読書補助中・拡大中は既存の操作を維持する。OSの動きを減らす設定では曲面アニメーションを省略する。
- 画像をデコードするまでは元ページを保持する。準備失敗時はアニメーションを省略して既存の描画へ戻す。画面サイズ変更で一時レイヤーを破棄する。
- `verify-viewer-page-curl-browser.cjs`で日英のボタン、タッチ確定／取消、単ページ／見開き、動きを減らす設定、作者データ不変を確認する。iPhone実機のフレーム安定性は別途確認する。
