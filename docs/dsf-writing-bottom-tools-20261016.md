# Writing 下部ツールバー（2026-10-17 更新）

iPhoneで同列展開時にペンを操作できなかった報告を受け、2026-10-16のReader操作列への挿入を取りやめ、独立したWritingツール列に戻す。

- スマホは上段にWriting、下段にReaderの情報・鉛筆・表示姿勢・ページ送り。Writingだけを横スワイプし、Readerボタンは動かさない。
- PCは全道具を下部に表示し、Readerの操作列は画面右端に維持する。
- Writingの並びは Undo／Redo・レイヤー・履歴 → 選択・文字・線・矢印・四角・楕円 → ペン類。PCではページ全体表示も履歴操作の列に置く。
- 道具グループは高さ44pxの透けるガラス調の枠で統一。薄いグラデーション、背景ぼかし、縁のハイライトで立体感を付け、白いベタ塗りを避ける。透明度を下げる設定・強制配色では読みやすさを優先。アイコン下の文字は非表示とし、アクセシブル名とツールチップは維持する。
- ペン類にも同じ高さの枠を設ける。元のSVGの質感、色と太さへの連動を保ち、上向きのペン先が枠から飛び出す。選択時は全体が上へ動き、軸の下部は枠内でクリップする。
- ペン画像上の太さ表示は数字だけにして少し縮小する。設定パネルでは単位を明記する。
- 設定パネルは選んだ道具の直上に8pxの間隔で配置。横位置を画面内へ収め、実際の内容の高さで下端を道具に揃える。狭い画面ではパネル内容をスクロールする。
- 設定内容とパレットはパネルの実幅に収め、縦スクロールだけを許可。ホイールイベントはReaderに伝えず、標準のパネル内スクロールを維持する。
- Reader内の設定パネルは非モーダル。別の道具を選ぶとパネルを閉じて切り替え、選択オブジェクトの未適用変更は取り消す。閉じる操作は「×」とEscape、スクリーンリーダー用の説明を維持する。
- パネルは実際のページ矩形とvisual viewportの共通範囲に収め、Readerの上部操作列より下に置く。同じ道具・履歴・レイヤーボタンの再タップで閉じる。
- 履歴はiOSのselectピッカーを使わず、最新順の行ボタンで直接表示。現在位置と選択位置を区別し、「この履歴に戻る」で復元する。履歴が少なければパネルを縮め、多ければ一覧を縦スクロールする。
- タッチ／マウス操作時の自動フォーカス枠を抑制。描画面とスクロール領域の大きな枠は表示せず、Tabによるキーボード操作ではボタンのフォーカスを表示する。
- 自動収納、上部ハンドル、切替／非表示ボタンは設けない。Writing終了時に道具列を閉じる。
- ページ入力とReaderボタンをスクロール領域に含めない。文字の直接入力中は入力UIを優先する。
