# Writing 下部ツールバー（2026-10-17 更新）

iPhoneで同列展開時にペンを操作できなかった報告を受け、2026-10-16のReader操作列への挿入を取りやめ、独立したWritingツール列に戻す。

- スマホは上段にWriting、下段にReaderの情報・鉛筆・表示姿勢・ページ送り。Writingだけを横スワイプし、Readerボタンは動かさない。
- ホーム画面から開いたPWAの縦画面では、Readerの最下段を通常ブラウザより下へ寄せる。下部safe-areaが34pxなら12px下がり、タップ領域の下に10pxを残す（丸いアイコン自体はその内側）。ページの大きさには連動させず、通常ブラウザ・横画面・PCの配置は維持する。iOSの`navigator.standalone`判定も利用する。
- PCは全道具を下部に表示し、Readerの操作列は画面右端に維持する。
- Writingの並びは Undo／Redo・レイヤー・履歴 → 選択・文字・線・矢印・四角・楕円 → ペン類。PCではページ全体表示も履歴操作の列に置く。
- 道具グループは高さ44pxの透けるガラス調の枠で統一。薄いグラデーション、背景ぼかし、縁のハイライトで立体感を付け、白いベタ塗りを避ける。透明度を下げる設定・強制配色では読みやすさを優先。アイコン下の文字は非表示とし、アクセシブル名とツールチップは維持する。
- ペン類にも同じ高さの枠を設ける。元のSVGの質感、色と太さへの連動を保ち、上向きのペン先が枠から飛び出す。選択時は全体が上へ動き、軸の下部は枠内でクリップする。
- ペン画像上の太さ表示は数字だけにして少し縮小する。設定パネルでは単位を明記する。
- 設定パネルは選んだ道具の直上に8pxの間隔で配置。横位置を画面内へ収め、実際の内容の高さで下端を道具に揃える。狭い画面ではパネル内容をスクロールする。
- 設定内容とパレットはパネルの実幅に収め、縦スクロールだけを許可。ホイールイベントはReaderに伝えず、標準のパネル内スクロールを維持する。
- Reader内の設定パネルは非モーダル。別の道具を選ぶとパネルを閉じて切り替え、選択オブジェクトの未適用変更は取り消す。閉じる操作は「×」とEscape、スクリーンリーダー用の説明を維持する。
- パネルは実際のページ矩形とvisual viewportの共通範囲に収め、Readerの上部操作列より下に置く。同じ道具・履歴・レイヤーボタンの再タップで閉じる。
- 履歴はiOSのselectピッカーを使わず、最新順の行ボタンで直接表示。現在位置と選択位置を区別し、「この履歴に戻る」で復元する。履歴が少なければパネルを縮め、多ければ一覧を縦スクロールする。
- タッチ／マウス操作時の自動フォーカス枠を抑制。描画面とスクロール領域の大きな枠は表示せず、Tabによるキーボード操作ではボタンのフォーカスを表示する。
- 時間経過による自動収納、上部ハンドル、専用の切替／非表示ボタンは設けない。ペン・図形・文字でページに書き始めると道具列（Undo／Redo・レイヤー・履歴を含む）を収納する。選択操作は対象外。
- Writing中の鉛筆の短押しは道具列の表示切替だけを行い、モードと選択道具を維持する。550msの長押し（キーボードはShift+Enter）でReaderへ戻る。10pxを超える移動やpointercancelで長押しを取り消す。
- 起動時または最後のファイル書き出しから履歴位置が変わっていれば、終了時に「編集用DSFRを保存」「ファイルに保存せず戻る」「書き込みを続ける」を提示する。保存はファイル準備後に利用者のタップでダウンロードしReaderへ戻る。元ファイルは上書きしない。保存せず戻る場合もReaderへの書き込み引き継ぎと端末内の下書きは従来通り維持する。
- Readerで原本を開いた後にWritingのモジュール・CSS・フォント目録を先読みする。原本のFontFace登録と描画コンテキストの準備はReaderのものを利用し、Writingで重複させない。DSFRの内容検証は維持し、その間は操作不能の道具列と準備中表示を先に出す。
- ページ入力とReaderボタンをスクロール領域に含めない。文字の直接入力中は入力UIを優先する。

## 検証

- 320〜1920pxの9種類の画面幅・高さとsafe-areaで、道具の枠の高さ、Reader下段との分離、PCで全道具表示、設定パネルの直上配置を検証。
- 1440×900ブラウザで3グループの高さが約44px、枠内の背景が透明、設定とペン画像の間隔が約8pxであることを確認。
- Chrome 390×844タッチエミュレーションで横スワイプ（0→350px）、筆ペン選択・描画・再タップによる設定表示を確認。内部の縦スクロール位置は0を維持。
- 390px・590px幅で蛍光マーカー／矢印の設定内容に横のはみ出しがないこと、ホイールで設定内だけスクロールすること、別のペン選択で閉じることをブラウザで確認。
- iPhone実機のSafariは未確認。今回の確認はローカル実装に対するもの。
- iPhone報告への追加修正として、390×844でページ内配置・再タップ・履歴の行選択／復元／Redo有効化とフォーカス枠非表示を確認。ページ矩形・ヘッダーを避ける配置は縦横4サイズの自動テストで確認。
- 起動・収納の変更は390×844のローカルブラウザで、筆記開始時の収納、鉛筆短押しによる再表示／収納、変更なし長押し終了、変更あり保存確認、終了キャンセル、保存ダウンロードを確認。取得したDSFRを`loadDsfV3`で再読込し、筆跡1件・履歴2件を検証。今回の入力検証はマウスによるPointer Eventsであり、iPhone実機の長押しは未確認。
