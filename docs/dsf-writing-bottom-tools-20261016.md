# Writing 下部ツールバー（2026-10-16）

Reader の鉛筆ボタンで下部に道具を展開する。2026-10-14 の横スクロール案、2026-10-15 の上部ドロワー案の配置・収納仕様を本仕様で置き換える。

- Reader の実際の操作列の鉛筆ボタン直後に道具を挿入する。「情報 → 鉛筆 → Undo／Redo・レイヤー・履歴 → 選択・文字・線・矢印・四角・楕円 → ペン類 → 表示姿勢 → ページ送り」の一列。展開時は左右の既存ボタンを外側へ移動する。
- スマホではこの列全体を横スワイプする。幅に余裕があるPC（通常サイズで1146px以上）では全ボタンを同時表示する。PCでも狭いウィンドウは横スクロールとし、タップ領域を縮めない。幅900px未満はコンパクトなペンと履歴操作を使う。
- ReaderとWritingの操作ボタンの中心高さを揃える。ペン先だけ上へ伸び、Readerの操作列と道具列を別の段に分けない。終了時は元のReaderの6ボタンに戻す。
- ペンは従来のSVG、陰影、色、太さ連動を保ち、画像全体を上向きに回転する。選択するとペン全体が上へ出る。mmの表示は正立したまま。
- 上部ハンドル、切替／非表示ボタン、時間による自動収納は撤去。Writingを終了すると道具列が消える。文字の直接入力中は従来どおり入力UIを優先する。
- 横移動はブラウザ標準のスクロールを使い、道具間の空白もスワイプ可能。移動時は長押しとクリックを抑止する。再タップ／長押しの設定表示、キーボード操作を維持。
- ツールチップは道具の上に出す。設定／レイヤー／履歴パネルは表示領域内に収める。
- スクロールはReaderの列だけが担当する。内部ラッパーは `overflow:clip` とし、タッチスクロールを閉じ込めない。ページ入力はviewport基準の固定配置を保ち、道具列をスクロールしても筆跡やテキストボックスの座標を変えない。
