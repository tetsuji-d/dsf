# Viewer Info Panel Spec

Updated: 2026-10-04

## Goal

作品情報と言語切替を、読書面の大きさを保って表示する。PCでは必要に応じてページ全体を左へ寄せる。
従来の下からせり上がる3段階シートは廃止する。

## State and operation

- 状態は `closed / full` の2つ。旧 `peek / summary` の呼出しは `full` に正規化する。
- iボタンで開閉する。閉じるボタン、Escape、パネル外のタップでも閉じる。
- パネル外で閉じる操作は、背面のページ送りやボタン操作に流さない。
- 開くと閉じるボタンにフォーカスし、閉じるとiボタンへ戻す。
- パネル全体を縦スクロールできる。閉じる操作は上部に固定する。
- パネル内のホイール・キー操作を、ページ送りや読書姿勢の変更に使わない。
- 下端スワイプ、ハンドル操作、展開・縮小ボタンは使わない。

## Placement

- 狭い画面ではページの表示枠に重なる固定ウィンドウ。黒70%（透明度30%）の半透明背景、白系の文字。
- ページ枠は現在の通常ページ、または読書表示の選択面を基準にする。
- 表示中もページのサイズ・選択位置を維持する。スマホではページ位置も維持する。
- 右側の操作列60pxと間隔16pxを除いた既存余白に320px以上確保できる場合は右隣に配置する。
  幅は最大420px、上部メニューを避けてページ下端まで表示する。
- 幅1024px以上のPCでは、左右の余白を合わせて情報欄320pxを確保できる場合、
  ページ全体を必要な分だけ左へ移動する。ページを縮めず、左端12pxと操作列の余地を残す。
  情報欄を閉じると中央へ戻す。収まらない場合はページ上へ重ねる。
- visual viewportとOSの安全領域内に収める。画面サイズ変更にも追従する。

## Content

1. 作品タイトル
2. 作品の言語（言語名と選択中のチェック）
3. レーベル・シリーズ・著者・公開期限（該当する項目のみ）
4. 概要
5. しおり
6. ライナーノーツ
7. レビュー

言語切替は上部ツールバーからここへ移す。UI自体の言語ではなく作品本文の言語を切り替える。
既存の言語ページ対応・保存・翻訳データは変更しない。
単一言語の作品ではその言語を選択状態で示す。

## Existing data and links

- 既存 `meta.{lang}` / `labelName` / publication / bookmark / review の読込・保存契約を維持。
- 外部リンク `{{テキスト|https://...}}` は別タブ、`rel="noreferrer noopener"`。
- 相対内部リンクは既存ルートに従い、それ以外の未対応schemeはリンク化しない。
- データ形式、権限、クラウド保存方式の変更は含まない。
