# Studio: 個人ローカル制作のオフライン対応

2026-09-28、feature/studio-local-pwa の実装。未コミット・未デプロイ。

## 対象と使い方

1. オンラインでStudioのダッシュボードを開き「オフライン利用を準備」を押す。
2. 「オフライン利用可」を確認する。アプリ本体、既存Firebase SDK、UIフォント、制作フォント、初期サンプルを端末に保存する。初回は数十MB以上の通信が必要。
3. 個人の原稿を端末で作成するか、画像等を内包したDSPを取り込む。サーバー上にしかない画像や任意の外部フォントは準備対象ではない。
4. 未ログインで編集・DSP保存・DSF出力ができる。対応ブラウザーではインストールボタン、iPhoneでは共有メニューからホーム画面追加を使う。
5. 再接続後に同じ準備ボタンで更新を確認し、更新ボタンから任意に反映する。

公開、チャット、共同編集、出版スペースのオンライン操作、クラウド保存のオフライン同期は対象外。Horizonの作品を丸ごと保存する機能、OSのファイル関連付けも含まない。

## 未保存警告と復元

- ローカル原稿の編集後はDSPファイル未保存を表示し、beforeunloadで離脱を警告する。
- IndexedDBへの自動保存、DSFの出力はDSP保存済みの根拠にしない。
- DSPダウンロードの開始後、端末にファイルがあると本人が確認したときだけ警告を解除する。キャンセル・失敗・確認保留では解除しない。
- 書き出し途中に編集、プロジェクト切替があれば古い保存確認は受け付けない。
- DSPを取り込んだ直後は保存済みとして扱う。ブラウザーの作業コピー復元時には外部ファイル保存の証拠がないため未保存として扱う。
- タブ非表示時にも既存の保留保存を実行する。モバイルOSの強制終了はイベントが来ない場合があり、警告・直前編集の保存を保証できない。
- ブラウザーのストレージ消去・容量回収ではキャッシュも原稿も失われうる。DSPの外部バックアップを残す。

## 保存・権限・更新境界

DSP/DSFのデータ形式と既存IndexedDBの保存方式を変更していない。共有編集の退会・失敗原稿保管は別変更。

Service Workerはビルド時に決まるアプリ資材、固定URLのSDK・フォントのみ事前保存。Authorization付きリクエスト、API、Firestoreデータ、公開作品データ、作者の画像を実行時にキャッシュしない。SDKの版は既存10.7.1を維持。

必要資材が一つでも欠ければ準備完了としない。インストール失敗は候補キャッシュのみ破棄する。更新を自動適用・自動再読込しない。ユーザーが更新した場合も離脱警告を維持し、再読込を取りやめた旧タブの遅延読込に備え旧版アセットを保持する。旧版キャッシュの世代整理は未実装で、原稿を巻き込む一括削除は行わない。

## 検証

- npm run verify:studio-local-pwa: ローカル警告、保存確認、編集中の競合、共有/クラウド除外、API非キャッシュ、フォント欠損、インストール失敗、旧版アセット参照。
- npm run build:staging: ビルド生成物の確認（ステージングへのデプロイではない）。
- project-persistence、shared-runtime、shared-recovery、dsp-publication-thumbnail-import の関連検証を実行。
- In-app Browserで通信を遮断し、準備済みStudioの再起動、新規作成、DSP保存、DSP再読込と画像復元、2ページDSF出力を実操作。取得したDSP/DSFをZIPのCRCと内容で確認。出力したDSFをオフラインViewerで表示。
- 未ログイン時に保存中表示が残るnull/空文字比較も修正し、保存済み(Local)とDSPファイル未保存の併記を画面確認。
- ブラウザーのbeforeunloadイベントと離脱キャンセル、PWA更新案内・更新後の復元を確認。
- 実機iPhone/Android、OSへのPWAインストール、全てのFlow/固定テキスト作品のオフライン出力は未検証。
- 既存 verify-flow-press-portable-download は press.js の古い関数形を前提とする正規表現で失敗。HEADの変更前コードにも同じ不一致があり、今回press.jsは変更していない。

## インストール案内

ダッシュボードの「端末への追加方法」はインストールイベントの有無にかかわらず表示する。Windows/Chrome、Mac/SafariとChrome、iPhone/iPad/Safari、Android/Chromeの操作を公式案内リンク付きで表示。インストール後のアプリでオフライン準備を確認し、ブラウザーとの作業コピー共有を前提にせずDSPで移すよう案内する。OSからDSPを直接起動するfile_handlers/launchQueueと元ファイルへの上書き保存はまだ未実装。
