# DSP / DSFのファイルアイコン

2026-10-02。ローカルファイル／PWA対応の続きとして追加。

- 共通: 白い書類、折り返し、濃紺の輪郭、拡張子バンド。既存Studioの「本」モチーフを引き継ぐ。
- DSP: 緑 (#087D72)、原稿の罫線とペン、DSPの文字。編集用原稿を示す。
- DSF: 青 (#2457C5)、見開きの本、DSFの文字。閲覧・配布用を示す。
- 色だけに依存せず記号・文字も変える。極小表示では記号と輪郭を優先し、拡張子はファイル名と併用する。
- SVGは文字もパス化し、外部フォントに依存しない。正本は public/file-icons/dsp.svg と dsf.svg。PNGは同じSVGを16/32/48/64/128/256/512pxにラスタライズしたもの。
- Studioのアプリアイコンは維持。ファイル種別のアイコンと、作品ごとの表紙サムネイルは別の役割。

## 適用範囲

インストール案内とPWA受信ファイル一覧に表示。studio.webmanifestの各file_handlers.iconsへPNGを登録する。既存のMIME・拡張子・起動先・launch_typeは維持。オフライン準備にアイコンを含め、アイコン内容の変更もキャッシュ版に反映する。

OS側の表示はPWAのインストール・更新、対応ブラウザー、既定の関連付けに依存する。Windows Explorer / Finderへの実反映は未検証。レジストリ変更、既定アプリの強制設定、ネイティブ拡張のインストールは行わない。ファイル形式・保存方式・公開データは変更しない。表紙サムネイル／内容プレビューのOS拡張は別途実装が必要。

## 確認

SVG/PNG寸法・透過、PWAの参照先、既存起動契約、オフライン資材一覧、stagingビルドを確認。ブラウザーのインストール案内・受信一覧で見た目と開く操作を確認。OSの実際の関連付け表示とは区別する。

仕様参照: [Chrome File Handling API](https://developer.chrome.com/docs/capabilities/web-apis/file-handling)（file_handlers.icons）。
