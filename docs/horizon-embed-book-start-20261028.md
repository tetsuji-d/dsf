# 埋め込みのブック表示・初期ページ（2026-10-28）

## 仕様

- リーズのURL横の埋め込みボタンから、通常表示／ブック表示（ページのしなり）と初期表示ページを指定する。
- 表紙を1とする通し番号。1以上の整数のみコピー可能。URLの不正値は1、総ページ数より大きい値は最終ページへ丸める。
- `view=flat|book&page=N` はコピーするコード単位の表示設定。版の内容、固定URL、公開状態、許可ドメインは変更しない。既存コードは通常表示・1ページ開始を維持する。
- 初期ロードは表紙とOpen Read.を維持し、本文・フォントの取得後に指定ページを開く。初回のページ送りは指定ページ基準、初回のバー指定はその指定先を優先する。
- 埋め込み右下に通常／ブック表示の切替ボタンを追加。Readerと同じ曲面表示を使う。スマホの単ページでは同じページ、PCの見開きでは同じ見開きを保持する。見返しを含む見開きは既存の代表ページ規則により通し番号の表示が変わる場合がある。
- 単ページ／見開きは埋め込みの幅と高さに応じて自動判定し、表示モードとは別に扱う。読書中のサイズ変更にも追従し、短い横向き枠では単ページを中央に表示する。
- 本文上の高速スワイプによる連続めくりは導入しない。ブック表示でもページ送り、バー指定、1操作ごとの横ジェスチャーを使用する。
- ロゴ・ページ送り・表示切替・全画面は下端の同じ高さ。多言語切替は右上へ移動。各操作域は44px、操作後の自動非表示は従来の約3秒。
- 閲覧判定は同一セッションを維持し、表示切替中・表示失敗中は成立させない。ブック表示では実際の曲面ページの準備完了／画像状態を確認する。

## 実装

`embed-layout.js` に安全な表示オプションと初回操作の解決を追加。`embed-policy.js` の生成コード、`edition-embed-dialog.js` の設定UIへ接続した。

`viewer-embed.js` の初回起動時に表示モード／初期ページを引き継ぎ、`viewer.js` から既存Reader chrome／edge peekを呼ぶ。表示切替中はボタンを無効にして二重遷移を防ぐ。公開確認失敗時は通常ページだけでなくブックと遷移レイヤーも隠す。

読書中のリサイズで通常表示側の見開き状態を流用すると、ブック表示の単ページ判定が古いまま残ることを検出した。ブック表示は現在の枠から判定し、単ページの隣の面を表示範囲外で切り取るよう補正した。通常Readerの単ページ表示にはこの切り取りを適用しない。

- `verify-reader-embed.js`、`verify-embed-access-refresh.mjs`、`verify-viewer-responsive-layout.mjs`、`verify-viewer-peek-geometry.mjs`、変更JSの構文検査、`build:staging` 成功。
