# Flow 段落の行揃え（2026-09-12承認・実装）

## 問題

2026-09-12、生成ページの「上に揃える」で、翻訳付き段落の分割制限が表示される。
`js/app.js` の `syncFlowPageSourceControls` は `flow-placement-inline` の操作を
`isolateFlowTitlePage` へ渡している。通常の行揃えをページ隔離・扉領域作成として扱うため、
ページ端が段落途中なら分割が必要となり、翻訳を持つ段落では拒否される。
前回の修正（同値操作を無変更にする・未操作の軸を保持する）だけでは解消しない。

## 操作仕様

- 通常の行揃えはカーソルのある段落全体に適用する。選択範囲がある場合は、その範囲と重なる段落全体に適用する。
- 縦書きは上／中央／下／両端、横書きは左／中央／右／両端。現在対応する書字方向に従う。
- 自動折り返しの各行や生成ページを保存対象にしない。同じ段落が別ページへ続く場合も書式を共有する。
- 原文・翻訳とも操作中の言語だけに適用する。本文、翻訳文、段落ID、注釈、画像の紐付けを変更しない。
- 行揃えでは段落分割、改ページ、扉領域作成を行わない。翻訳付き段落の分割禁止は維持する。
- ページ内の行のまとまりの配置（縦書きの左右／横書きの上下）と扉指定は別操作として表示する。
  現在の「このページ／Flow全体」は通常の段落行揃えの対象指定には使わない。
- リボンのツールチップを「段落の行揃え」と「ページ内配置」に分ける。混在する選択では単一の値を選択済みに見せない。
- 複数段落への適用もUndo 1回で戻す。選択変更だけでは書式を書き換えない。
- 過去の操作で保存済みの中央配置等は自動リセットしない。作者の意図との区別ができないため。

## 保存仕様（2026-09-12 Architect承認）

FlowDocumentのparagraph／headingに任意の言語別行揃えを追加する。

```json
{
  "id": "paragraph-id",
  "type": "paragraph",
  "texts": { "ja": "本文", "en-GB": "Text" },
  "textAlignByLanguage": { "ja": "start", "en-GB": "center" }
}
```

- 値は `start | center | end | justify`。未指定は既存設定を継承する。
- 優先順位は段落の当該言語設定 → 既存扉領域のtextAlign → 言語別Flow組版設定 → start。
- 明示的に機能を使用したFlowDocumentだけschemaVersion 5へ進める。既存v1–v4の自動変換はしない。
- Project v6、DSP外枠、FlowLayout、配信DSF v2の形式は維持する。
- 古いEditorは未知のFlowDocumentバージョンとして編集を停止し、書式を無視して再保存しない。
- 原文テキストの変更ではないため、この操作だけで翻訳を未確認・古い翻訳へ変更しない。
- 元原稿画面、クラウド保存、DSP往復、Undo/Redoで保持する。履歴や生成ページだけへの一時保存にしない。

## 接続箇所

1. `flow-document.js`でv5と新フィールドを厳格に検証する。既存機能がschemaVersionを4へ戻さないようにする。
2. `flow-authoring.js`へ行揃えのコマンドを追加する。段落ID、言語、本文と従前書式を照合して一括適用する。
   段落分割時は書式を継承し、結合時は異なる書式を無断で失わない。
3. `app.js`／`studio-flow-ribbon.js`で段落行揃えをページ隔離処理から切り離す。
   キャンバス・原稿画面の選択から対象段落を決定し、入力確定中や再組版中の古い選択は使わない。
4. `flow-pagination.js`のfragmentへ当該言語の書式を投影し、`flow-dom-measurer.js`の実測・描画へ同じ値を適用する。
5. 通常ページと画像回り込みの組版、計測キャッシュ、増分再ページ化の署名を揃える。
6. `flow-publication-projection.js`で書式が原稿と一致することを検証する。
   Press／印刷／Viewerへは既存の実測済み固定行座標として配信する。

## 完了確認

- 翻訳付きの長い段落がページをまたぐ状態で、縦書きの上／中央／下／両端を実操作する。
- 同じ条件の英語横書きでも動作し、日本語側の書式・翻訳状態を変えない。
- 複数段落、段落途中の選択、選択末尾が次段落先頭の場合、混在書式、同値クリックを確認する。
- 段落の個数・ID・本文・翻訳・注釈・画像アンカーが操作前後で同一であることを確認する。
- 画像回り込み、ルビ・圏点、ページをまたぐ継続段落でも実測と描画が一致する。
- Undo/Redo、保存再読込、DSP往復、プレビュー・印刷・DSF発行の表示を確認する。
- 明示的な扉ページ作成と翻訳保護の既存検証を維持する。

実エディター、原稿画面、言語別保存、通常／画像回り込み組版、固定テキスト発行に接続済み。コミット・デプロイは別途依頼後に実施する。

複数段落選択は既存の原文キャンバスの選択機構に従う。翻訳キャンバスと原稿画面では現在の段落に適用する。
この機能では生成ページの途中を新しい段落境界として保存しない。
