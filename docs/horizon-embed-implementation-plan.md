## 実装順

### 1. 契約確定と先行検証

仕様案の初期値off、許可サイト形式、5秒／50%、30分計測窓、保存30日を実装単位の契約として確定する。
`docs/data-model.md` へ設定原本、新イベント、重複キー、集計・保存期限、Rulesの差分案を整理してから適用する。
通常Readerの描画・イベント依存を調べ、流用するcoreと埋め込みshellを分ける最小境界を決める。Reader全体の大規模な同時リファクタは行わない。
Safariの外部iframe内で可視性・storage制限・全画面代替を先に試作する。判定不能時の時間計測fallbackは仕様どおり過少計上側へ倒す。

完了条件: 固定テキスト／WebPを共通処理で表示でき、ページの画質・改行が変わらない。計測状態機械の入力と除外条件が決まる。

### 2. 閲覧集計を先に分離

新規候補 `js/reader-view-session.js` に可視時間・明示操作・読み込み成功・セッションの状態機械を作る。
新規候補 `functions/api/reader-metrics.js` とserverモジュールにticket発行、受付検証、同時送信の重複排除、日次集計を置く。
serverの時刻・版identity・公開状態・制限を検証し、イベントの確定とカウンター更新を単一transaction等で整合させる。
匿名IDとticketの有効期間・保存禁止環境の縮退を実装し、連打・再読込・複数iframe・タイムアウト再送を検証する。
新指標へ切り替えた後も旧タブが送るschemaVersion 1は旧系列に隔離する。切替日と「読み込み回数→条件付き閲覧数」の定義変更を管理画面へ表示する。
旧イベントは遡って実閲覧へ換算できない。新集計の画面は履歴を混ぜず、旧送信口の終了は配信済みclientの互換期間を決めて別途行う。

完了条件: 初期ロード0view、条件成立1view、同時／再送も1view、別版は独立。非公開化・偽造ticket・過剰発行を拒否。送信失敗でも読書可。

### 3. 埋め込みポリシーとHTTP入口

`server/editions.js`／`js/edition-policy.js` に設定更新actionを追加する。更新署名へ設定値を含め、revision競合を検出する。
新規候補 `functions/embed/[editionId].js` が設定と公開状態を検証してshell・CSPを返す。エラー応答でもヘッダーを欠落させない。
通常Readerの全入口には外部frame拒否を設定。単なるclient側 `window.top` 判定やCORSだけで代用しない。
shell生成用静的ファイルが外部frame用の無制限入口として残らないようにし、旧ホスト・別名・rewriteも検証する。
公開変更・埋め込みoff・許可ドメイン削除は、次のHTML要求と状態確認に反映。permission応答のCDN/SWキャッシュ混入を防ぐ。

完了条件: 許可元は表示、禁止元・不許可の祖先は拒否、Refererなしでも正しく制御。通常リンクは許可設定によらず公開状態に従って閲覧可。

### 4. DSF向け埋め込みReader

本文描画・言語・固定レイアウト検証は既存処理を共有し、必要な操作だけを持つshellを接続する。
表紙→読む→本文、操作バー、拡大／戻る、通常Readerで開く、読み込み・失敗・再試行・公開終了の各状態を実装する。
読む前に本文・フォント・他言語を先読みしないことをネットワークで確認。計測は工程2の共通契約だけに接続する。
埋め込みではSW登録やログインpopupを起動せず、第三者storage不可でも読めるようにする。

完了条件: 9:16が保持され、スマホでページと操作が見切れず読める。画面外・背景タブ・ロード失敗でviewが増えない。

### 5. リーズの設定・コード生成

共有・埋め込み画面、3択、ドメイン入力、保存競合、日英文言、表示見本を追加。
コピーするコードは環境に合う固定editionURL、読み上げ用title、lazy loading、必要最小限のfullscreen許可、レスポンシブ枠、iframe外の通常リンクを含める。
任意HTMLや任意ドメインをコードへ未エスケープで挿入しない。親サイト用の必須JavaScriptは初期版に設けない。
表示見本はlive集計に入らない専用previewとして作る。禁止設定でも表示見本を実サイトでの許可確認と誤認させない。

完了条件: PC・スマホで設定→保存→コードコピーが完了し、別サイトへ貼ったコードが動作する。コード生成は版の公開状態を変えない。

### 6. staging統合検証とレビュー

工程2〜5の依存が揃ってからstagingへ反映する。ページ配信だけでなくFunctions、Rules、集計保存面の環境を確認する。
別々のHTTPS originの許可サイト／禁止サイトにテスト用埋め込みページを作り、入れ子iframeも確認する。
mainマージと本番反映は別工程とし、現時点では実施しない。

## 受け入れ試験

| 分類 | 必須の確認 |
|---|---|
| 通し操作 | Studio発行→非公開のリーズ→公開／限定公開→埋め込み設定→別サイトで読む→通常Readerへ移動 |
| 版固定 | 初版と第二版の本文・URL・設定が独立。旧リンク・旧埋め込みが別版に置換されない |
| 公開制御 | public/unlisted/private/archive/restore/discard、期限切れ、運営停止。復元は非公開 |
| ドメイン | off/any/allowlist、www違い、未登録サブドメイン、Refererなし、悪意のある入力、無許可祖先、多重frame、通常URLによる迂回 |
| 変更反映 | 閲覧中にoff／許可先削除／非公開。再読み込み・復帰・状態確認で拒否し、通信失敗も許可へ倒さない |
| 集計 | 表紙ロード0、読む直後0、5秒またはページ送りで1、連打・再送・再読込重複なし、画面外・背景・未描画0 |
| 集計境界 | 一頁作品、巨大iframe、途中まで見える枠、複数iframe、複数タブ、言語切替、自動しおり復元、storage禁止、30分境界、owner preview |
| 配信 | v1 WebP、v2固定テキスト・混在、縦書き／横書き、多言語、空表紙、長い題名、低速回線、オフライン再試行 |
| 画面 | PC1280/1440、スマホ360/390/430、768、中間幅・横向き、ライト／ダーク、フォーカス・戻る・44px操作、スクロール位置 |
| ブラウザー | Chromium・Firefox・WebKitと、実機iPhone Safari・Android Chrome。幅エミュレーションと実機結果を分けて記録 |
| 負荷 | 同一ページの多数iframe、読む前後の通信量、初回本文表示時間、ticket発行と集計の書込数・受付上限 |

各幅でDOM寸法だけでなくスクロール後の画像と実操作を保存する。実機が未確認なら完了扱いにしない。
数値はブラウザー上の表示だけでなくserverの受理イベント／重複キー／日次集計と突合する。

## 公開・切戻し

機能フラグで新規コード生成を制御し、初期は少数のstaging版だけで検証する。
問題時は埋め込み入口を閉じて通常Readerリンクを残す。過去の版やURLは削除しない。
指標の切戻しでもloadイベントを新viewへ混入させない。新しい設定と集計データは破壊せず保持し、再開時にrevisionを照合する。
