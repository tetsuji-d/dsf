# Writing: スマホの文字入力と上部道具列（2026-10-14）

## 変更

- 幅900px未満では「Undo／Redo・レイヤー・履歴 → 道具 → ペン → 非表示ボタン」を一つの横スクロール列に配置する。PCのページ全体ボタンと従来配置は維持する。
- 操作ボタンも道具と同じ親コンテナに置き、3.5秒の自動収納と上端からの再表示を同じ動き・タイミングに統一する。横スクロール中は収納までの時間を延長する。
- 選択中の道具の色・名前・設定値は列の下の設定ボタンに表示。マウス／キーボード向けのツールチップも統一する。
- スマホの文字入力は「Aa・サイズ−／数値／＋・キャンセル・確定」の小さなバーを基本にする。Aaを開くと書体・代表サイズ・色・枠線・塗りの設定が現れる。
- 入力中はWriting道具列とReaderのページ操作を一時的に隠す。入力開始時のページ倍率を保持し、テキストボックスがバーとキーボードの間に見えるようページを移動する。終了すると通常のReader配置へ戻す。
- Reader基本UI、ペン画像、保存形式、履歴上限は変更しない。
