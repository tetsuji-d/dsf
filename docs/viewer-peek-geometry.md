# 覗き見表示の紙面形状

## 基準

- A面は手前、B面は中間、C面はカバー側の紙面。
- 各紙面は360×640（9:16）。ノドから小口までの**曲面に沿った長さ**を360に保つ。
- 背表紙とC面の小口端は共通の机の面（断面のz=0）に接する。左右の本文は共通のノドでつながる。
- C面は両端の間で外側へ膨らむ。A・B面も同じ曲線系を使い、開き角度を変えて前後の内容を露出する。
- 反りの山はノド寄り。横方向のノド〜小口の距離の約1/3に置く。曲面に沿う距離と、投影後の見かけの横幅を混同しない。
- 平行な斜投影で奥行きを表現し、遠近による拡大縮小・ピントぼかしは加えない。紙面の縦方向は常に640。

## 実装

`js/viewer-peek-geometry.js`が断面、紙幅、投影、画面への収まりを担当する。
曲線の長さを積分し、原稿の横位置を曲面上の距離へ対応させる。単純な横方向の引き伸ばしはしない。

狭い画面では反りを深くして横幅を収め、画面全体には縦横共通の倍率を適用する。
背表紙を前へ持ち上げたり、C面の端を机より奥へ動かしたりして収めない。
分割位置は曲線の誤差に合わせて配分し、スマホ16分割・PC24分割の既存上限を保つ。
曲線の計算結果は上限付きキャッシュで再利用する。

閉じたC1・C4の表示、読書位置、見開き順、ページ送りと途中停止の操作は既存の処理を使う。

## 検証

`node scripts/verify-viewer-peek-geometry.mjs`

紙幅360、紙高640、机への接点、ノドの接続、反りの位置、前後ページの露出、
スマホ・タブレット・PCでの収まりと分割誤差を検証する。
ブラウザーでも文字・画像を含む公開作品で、ページ送り、途中停止、C2/C3境界、C1/C4反転を確認する。

## 後続の読書モード

A面だけを読む「本の読書モード」は今回の変更に含めない。
導入時は横幅に余裕がある画面で利用できるようにし、狭いスマホ画面では自動的にスキップする。
通常表示・覗き見表示と同じ読書位置を共有する。
