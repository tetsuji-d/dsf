# Writing 道具ドロワー・矩形選択・筆跡の調整

## UI

- スマホの浮いたピル型取っ手を廃止。上端中央に32×3pxの目印だけを置き、操作領域は88×44px確保する。下へ引いて開き、道具列を上へ払って閉じる。目印のタップ・キーボードでも開閉できる。
- 横スクロールバーは非表示。Undo/Redo・レイヤー・履歴、道具、ペンの順序とネイティブの横スワイプを維持する。
- ペン軸は画面外まで伸ばす。線幅はペン先の横幅にも連続的に反映する。軸・金属部分の形状と質感は維持する。
- Readerの表示・アカウント・ページ送りを維持。選択時の操作メニューは、幅が足りる場合は紙面内に収めて側面のページ送りを避ける。

## 矩形選択

- 個別選択の隣に点線の矩形アイコンを追加。現在のページ内で完全に囲んだ、ロックされていないオブジェクトを選択する。
- 選択後は各筆跡の輪郭を表示。選択した筆跡をドラッグしてまとめて移動する。
- 切り取り・コピー・貼り付け・複製・削除・ロックを一括で実行できる。相対位置を保って移動・複製し、操作ごとに本全体の履歴を一件追加する。
- 個別のポイント編集は一件選択時に限る。ページ変更、道具変更、Undo/Redoで選択を解除する。見開きの両ページをまたぐ矩形選択は今回の対象外。

### 追加修正: 選択の統合と一括書式

- 矩形選択の独立ボタンを廃止し、選択・移動ツールに統合。オブジェクトを押すと個別選択、空白からドラッグすると完全に囲んだロックされていないオブジェクトを選択する。選択中のオブジェクトからドラッグすると一括移動する。
- 複数選択の「設定」で色と線幅を変更できる。ユーザーが操作した項目だけを一括適用し、未変更の色・線幅、矢印先端、線種、筆圧、墨量、カスレ、重ね順を保持する。色や幅が混在している場合は混在と表示する。
- 文字は各runの色のみ変更し、文字サイズ・書体・組版位置・枠線を保持する。線幅は筆跡・線・図形に適用する。ロックされたものは対象外。
- 「適用」まで原稿データを変更せず、キャンセルで破棄する。一括変更は履歴一件としてUndo/Redoできる。保存形式は変更しない。
- 自動検証: 色のみ・幅のみ、文字run、筆圧・カスレの保持、未選択・ロック除外、一括Undo/Redo、ZIP再読込、原本バイト保持。390×844のブラウザーで統合選択、二件の色・太さ変更、キャンセル、Undo/Redoを確認。実機iPhoneは未確認。
- ユーザーの指示により、この追加修正をコミットしステージングへ反映する。

### 共通メニューの端末ファイル導線

- Readerの「この端末のファイルを開く」に、共通メニューと同じMaterial Iconsのフォルダーアイコンを追加。日本語・英語の切替でもアイコンを保持する。
- Horizonにも同じ項目を追加し、Readerのファイル選択画面へ移動する。Reader内からは従来どおり端末のファイル選択を開く。
- スマホ幅でアイコン・文言・HorizonからReaderへの遷移を確認済み。

## 筆跡

- 蛍光マーカーは進行方向に合わせて矩形のペン先を回転させ、縦・横・斜めとも指定した最大幅を保つ。端は角を持つ。描画とヒットテストで同じ形状を使用する。
- 筆ペンのカスレは入力座標と時間から求める速度を主成分とする。速い区間はカスレ、遅い区間は濃くなり、再び遅くすると墨が戻る。距離による乾きは弱く残す。区間境界では値を平滑化する。
- 既存のgeometryVersion 4とdryness値を使う。保存形式・原本データは変更しない。速度を保存していない過去の筆跡から速度を復元することはしない。マーカーの描画変更は既存のマーカーにも適用する。
