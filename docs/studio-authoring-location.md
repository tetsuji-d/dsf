# この端末とクラウドの制作場所

2026-09-28。feature/studio-local-pwa。ユーザー承認済みの制作場所分離。

## 動作

- 新規作成時に「この端末で作成」またはクラウドの保存先を選択。マイスペースはクラウド、出版スペースは本人所有の現在の一覧から選ぶ。参加スペースの権限は拡張しない。
- この端末の原稿は、ログイン済みでも原稿・追加画像・表紙・サムネイルを自動アップロードしない。標準の保存/Ctrl+SはDSPファイル保存。ブラウザの自動保存は「復元用コピー」と表示し、DSP保存完了と区別する。
- DSP読込は独立したローカル原稿。古いprojectId/workId/Release/所有者/クラウド保存マーカーを引き継がない。本文・画像・装丁・言語メタを保持する。クラウド原稿一覧から開く場合は既存の同一原稿保存を維持する。
- 「クラウドに保存」は、本人の保存先一覧を確認した後で新しいクラウド原稿を作り、必要なら出版スペースに所属させる。保存や所属設定が失敗した場合、開いている画面では同じIDで再試行。保存途中にアカウント・原稿が変わった場合は後続の所属更新を止める。
- 所属設定に失敗すると原稿自体はマイスペースに保存済みの場合がある。保存と所属の一括トランザクションではない。画面を閉じた後はクラウド一覧で保存先を確認し、必要なら既存の所属変更操作を使う。
- この端末からHorizonへ進む際も先にクラウド保存先を案内する。保存後に既存の出版スペース・配信検証・下書き保存処理へ進む。公開・共有は従来の明示操作が必要。
- オフラインでのローカルDSP保存/DSF書き出しは継続。再接続時の本文の自動マージは追加しない。クラウド原稿の既存競合・復旧契約はcloud-save-contract.mdに従う。

DSP/DSF・Firestoreのスキーマ、公開境界、権限ルールは変更しない。新しい初期原稿は外部画像取得を必要としない空の画像ページにする。既存原稿の本文やViewer形状は変更しない。

## 検証

- verify-authoring-location: DSPの本文/装丁/画像保持とID分離、既定保存がDSPとなる分岐、実際の画像準備関数の保存先（ログイン済みローカル/オフライン/クラウド/共有）、クラウド保存失敗/所属失敗の再試行とアカウント変更。
- 既存のhome-start/dashboard-progressive、project-persistence、auth-save-status、local-pwa、editor-save-status、editor-image-import、shared-images/shared-runtime、Press startup/Horizon handoff/upload/draft/portableを確認。
- portable検証の旧関数呼出パターンを現行の設定変更ハンドラーに合わせて更新。製品の書き出し処理は変更しない。
- 隔離UIで端末作成、マイスペース/出版スペース選択、未ログイン・オフライン・カタログ取得失敗/アカウント変更、キャンセルを操作。
- 実Studioでローカル新規作成、DSP読込、標準保存のDSPダイアログ、Horizon前のクラウド案内、Flow DSFの生成・ダウンロードを確認。検証用DSFは約4.35MB。実アカウントの原稿保存・Horizon発行は実行しない。
- PC/390px幅はブラウザ相当環境。実機iPhone等とは区別する。
