# Viewerの表紙ループと全画面表示

## 読者の操作

表紙C1で逆方向へ進むと、本全体を裏返す途中の背表紙で止まる。
指を離し、同じ方向へもう一度送ると裏表紙C4に移る。逆方向ならC1に戻る。
C4からさらに逆方向へ進めばC3・本文末尾へ開く。C4の外側へ進む操作も同様にC1へ戻る。
ボタン・矢印キーも1回目で背表紙、2回目で反対側の表紙。RTLとLTRは左右が逆。
タッチ・マウスドラッグ・トラックパッド横スクロールは移動量に追従する。
同じ操作中は90度を超えず、横スクロールの慣性も同じ操作として扱う。

PCではヘッダー右上の全画面アイコンから全画面表示に入り、同じボタンまたはブラウザーのEscで終了する。
Fullscreen APIが利用できない環境にはボタンを表示しない。スマホ幅のタッチ端末ではボタンを隠す。

## 描画・保存境界

- 本文のページめくりとは独立したCSS 3Dの一時表示。WebGLは使用しない。
- 背表紙は作品タイトルを載せた暫定の共通デザイン。作者による背幅・画像・雑誌の閉じ側表示の設定、袖、帯は未実装。
- 表紙は既存の画像／固定テキスト描画を利用し、表裏両面の画像準備が済むまで元ページを残す。
- 背表紙はページとして数えない。90度ではページ位置とプログレスを保持し、裏返し完了時だけ既存ナビゲーション・しおり保存へ渡す。
- キャンセル、Esc、別ページへのジャンプ、言語切替、ファイル読込、表示モード変更、画面サイズ変更では一時表示を破棄する。
- prefers-reduced-motionでは吸着・完了のアニメーション時間をゼロにする。背表紙で止まる操作段階は維持する。
- book.coversがある作品はC1/C4を利用する。旧形式で表紙情報のない偶数ページ作品は、既存の見開き規則に合わせて先頭／末尾を外側の表紙とする。bookMode:noneの作品と、表紙不明の奇数ページ作品はループさせない。
- 保存フォーマット、Firestore、R2、作者の原稿データは変更しない。

## 確認方法

`/viewer?src=/scripts/fixtures/viewer-cover-loop-book.json` は架空の8ページを実Viewerへ読み込む開発用確認URL。
`/scripts/fixtures/viewer-cover-loop-ui.html` は独立した操作試作。

`DSF_PLAYWRIGHT_MODULE` をPlaywrightのモジュールパス、必要なら `DSF_VIEWER_TEST_ORIGIN` をローカル開発サーバーに設定して、
`node scripts/verify-viewer-cover-turn-browser.cjs` を実行する。
RTL/LTR・単ページ/見開き、背表紙からの復帰、裏表紙から本文への移動、ホイール慣性、タッチ中断、画面回転、全画面開始/終了、言語切替、スライダー割込を実Viewer上で確認する。

実際のスマホとトラックパッドの慣性・操作感は別途実機で確認する。
