# Flow 翻訳比較キャンバス

2026-09-09 / `feature/flow-layout-foundation`

## 操作

- Flowの生成ページを選び、リボン「表示」の「通常｜分割」で切り替える。
- 左は原稿言語、右は選択した翻訳言語。左右とも既存の生成ページ直接編集を使用する。
- 横スクロールは既定で同期。ページ番号ではなく、Flow Group／Section／Block IDの対応と、その間の読書位置から移動量を補間する。画像などFixedページも共通IDの境界として扱う。翻訳の文章内の単語対応を推定するものではない。
- 「同期」で独立スクロールへ切替可能。左右境界はドラッグまたは左右矢印キーで30〜70%に調整できる。
- クリックした段落を両側で強調。ヘッダーの矢印は前後の段落へ移動する。
- 原文更新後も保存済みの翻訳を表示し、古くなった段落を「要確認」と色で示す。チェックアイコンは選択した翻訳段落だけを現在の原文に対して確認済みにする。本文・ルビ・他言語は変更せず、既存Historyで取り消せる。
- 翻訳アイコンからキャンバス内の設定パネルを開き、既存Provider／モデル選択と翻訳ジョブを実行・中止する。手動訳保護と一括Undoは既存処理を使用する。
- 未翻訳箇所は編集専用の空欄と「未翻訳」表示。クリックして直接入力でき、入力した時だけ該当言語の本文を保存する。フォーカスだけでは空文字を保存しない。通常表示の原文fallbackは編集不可のまま維持する。
- IME変換中・直接編集の再組版待ちにはモードや比較言語を切り替えない。
- 原稿画面へ移ると通常表示へ戻る。画像などFixedページを選択しても分割表示は維持し、選択した側の言語で既存の画像編集を利用する。

## 境界

`state.blocks`が唯一の原稿。二つの`createFlowCanvasView`を表示し、アクティブな側だけが既存の入力proxy、semantic transaction、Undo/Redo、保存処理を使う。

比較用paginationは`sessionScope: 'editor-compare'`に分離。古い翻訳の表示と欠落箇所の空欄補完はこのscopeに限定し、空欄は一時的な文書コピーにだけ置く。保存済み本文やtranslationStateの鮮度を表示目的で変更しない。

通常表示・Pressの既存fallback／発行条件は変更しない。Firestore Rules、DSP/DSF schema、Viewerの仕様変更はない。翻訳側の段落分割・結合等の共有構造編集制限は既存どおり。

## 検証

`node scripts/verify-flow-translation-compare-browser.cjs`（ローカルVite、隔離Chrome、`DSF_PLAYWRIGHT_MODULE`指定可）。左右の編集、Undo、翻訳保持、default resolverのfallback、段落確認、スクロール同期／独立、リサイズ、言語切替、未翻訳の非保存、原稿への復帰、IME中の切替防止を確認する。

既存`verify-studio-ribbon-browser.cjs`、`verify-studio-ribbon-followups-browser.cjs`、`verify-flow-direct-edit.js`、`verify-flow-authoring.js`およびstaging用ビルドも実行。OS固有のIME候補ウィンドウは実機での確認対象。

「原稿を開く」は全文を効率よく編集するモードとして維持する。原稿上のホイールはキャンバスのズーム処理へ渡さず、原稿や入力欄を通常スクロールする。

## 全文原稿の分割表示

原稿モード上部にも「通常｜分割」を配置。左の原文と右の選択言語を、既存の全文編集ビューで編集する。入力欄の所属言語を使い、原文と翻訳の本文を分離して更新する。段落IDの対応でホイールスクロールを同期でき、「同期」を解除すれば独立して移動できる。選択した段落を両側で強調し、IME中は反対側への編集切替を止める。表示設定は原稿データへ保存しない。
