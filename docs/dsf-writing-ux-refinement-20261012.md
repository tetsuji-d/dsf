# Writing UI改善 — 2026-10-12

監査で挙げた順序に沿って、配置、道具の見た目、設定・レイヤー操作を改善した。Readerのページ表示・ページ送り・情報ボタンの実装、原稿の縮尺、元のペンSVGは変更していない。

## 配置と道具

- Readerが実際に表示している原稿・操作ボタンの矩形、画面の幅・高さ、safe areaからWritingの配置を計算する。
- 広いPCでは原稿左の余白へペンと道具を中央揃えでまとめ、Undo／Redo／全体表示／レイヤーもその近くへ置く。設定は右の余白が340px以上あれば原稿脇に表示する。
- 844×390の横向きでは左の空き領域にペン、3列×2行の道具、履歴操作を置き、Readerボタンとの重なりを避ける。
- 768pxのタブレット幅では全道具を表示する。全道具が収まらない画面では従来の1個の切替を維持する。667×375も切替式でReader操作を避ける。
- 320px幅でもペン・道具の操作幅は約44 CSS pxを確保。道具6個が横に収まらない上端では、メニューボタンより下へ道具の行を置く。
- ペンのSVGと描画エンジンは維持。画像と操作領域の幅を揃え、全体が平行移動する選択アニメーションを維持した。周囲のアイコン、選択色、線幅、ボタン寸法を統一した。
- 収納中は現在の道具を示す小さな取っ手を表示。上端の操作領域を44px高にした。マウスオーバーで展開した直後のクリックが原稿へ貫通しないよう保護した。
- 自動収納とUndo群の連動を維持。キーボードで道具を操作中はフォーカスごと隠さない。

## 設定・レイヤー・選択

- 既存オブジェクトの設定は「選択した書き込みの設定」と表示し、パレットのスクロールに関係なく「適用」「キャンセル」を固定表示する。キャンセル時は確定前の設定を戻す。
- 通常の道具設定と、既存の筆跡への変更確定を区別した。
- 横長で高さの低い設定パネルは、左に太さ・墨量・見本、右にカラーを並べる。画面回転でパネルを閉じずに配置を更新する。
- レイヤーパネル内にUndo／Redoを追加。ロック、削除、ドラッグの操作領域を44pxへ広げ、ロックと削除を離した。
- ドラッグ時の自動スクロールを新しいパネルのスクロール領域へ接続した。
- 枠だけの楕円・四角、筆跡、線は実際の線に近い場所で選択する。空の内側が下のオブジェクトの選択を妨げない。塗りつぶし図形、矢印、マーカーの長方形筆跡も判定に含める。
