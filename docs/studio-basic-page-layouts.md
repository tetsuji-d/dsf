## 言語・組み方向・ページ進行の対応（2026-10-21 追記）

前段の横書きのみの実装を、次の仕様に更新した。

- 原稿言語は編集中の言語キーをそのまま使用する（例: `en-us` を `en` に書き換えない）。UIの表示言語と原稿言語を分離する。
- ページ進行は作品の当該言語の `pageDirection` を継承する。文字のLTR/RTLとは別に表示し、基本レイアウト追加では作品設定を変更しない。
- 組み方向は、選択Flowの言語別組版設定、選択固定ページの文字オブジェクト設定を優先する。空ページや縦横混在ページでは作品設定へ戻し、その理由を画面に表示する。手順の数字のみのオブジェクトは縦横混在判定から除外する。
- 追加前のダイアログに、言語・組み方向・文字方向・ページ進行・初期値の取得元を表示する。「このページの組み方向」を変更すると6枚のサムネイルと詳細プレビューを更新する。
- 日本語・繁体字中国語は縦書きと横書きを選択できる。他言語は既存言語プロパティで対応している組み方向のみを提示する。
- 縦書き用に全6種の文字枠・写真枠・見出しの位置を設計し、3つの手順は右から左に読む列配置とした。横書きの手順番号は文字方向に従い、日本語・英語等は左側、アラビア語等は右側に配置する。ページ進行では反転しない。横書きの段落方向は原稿言語から判断するため、日本語横書き＋ページRTLを区別できる。

- 縦書きグラフィックの長音符・句読点は既存の `verticalGlyphText` を再利用する。横書きグラフィックのCanvas描画と直接編集欄に言語の文字方向を適用する。

- 保存形式を追加せず、既存のオブジェクト `style.writingMode` と言語別 `texts`、作品の `languageConfigs` を使用する。
